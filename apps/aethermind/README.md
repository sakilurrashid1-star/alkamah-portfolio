# ✦ AetherMind — Decision Intelligence Lab

AetherMind is an interactive decision-intelligence experience built as a zero-dependency web app.

Instead of pretending to be an oracle, it exposes the variables behind a recommendation and lets the user challenge them.

## What makes it different

- **Living decision model** — ambition, risk tolerance, time pressure, resources and uncertainty continuously reshape the result.
- **Explainable scoring** — the Decision Trace shows how the model reached its confidence score.
- **Counterfactual futures** — Safe, Base and Volatile worlds show how sensitive a decision is to the environment.
- **Adaptive timeline** — the suggested execution sequence changes with the modeled constraints.
- **Challenge the model** — deliberately perturb assumptions and observe how the recommendation changes.
- **Objective modes** — optimize for impact, stability, speed or learning.
- **Premium responsive interface** — designed as a product experience rather than a classroom calculator.
- **No backend or API key** — everything runs locally in the browser.

## Concepts demonstrated

Decision modeling • weighted scoring • scenario analysis • uncertainty • sensitivity analysis • explainability • human-in-the-loop systems • responsive UI engineering.

## Run locally

Open `index.html` directly in a modern browser, or serve the folder with any static web server.

## Scope

AetherMind is an educational simulation. Its scores are generated by a transparent heuristic model; they are not predictions, financial advice, medical advice, or claims about real-world outcomes.
