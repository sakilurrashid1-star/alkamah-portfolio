# CareerLens — Data-Driven Career Intelligence

An interactive, browser-based career intelligence dashboard built with **HTML, CSS and JavaScript**.

## What it does

CareerLens turns a user's selected skills into an explainable career signal. It provides:

- 🎯 Role-fit scoring across Data Analyst, Data Scientist, ML Engineer, Full-Stack Developer and Cybersecurity Analyst
- 🧩 Core and supporting skill-gap analysis
- 📈 Illustrative market signals for compensation, demand and remote friendliness
- 🗺️ Personalized three-step learning roadmap
- 🔎 Action-oriented decision guidance
- 📱 Responsive UI with no backend or build step

## Scoring approach

The score is intentionally transparent rather than pretending to be a black-box AI model:

- 75% — matched core skills
- 25% — matched supporting skills
- small experience adjustment for Junior/Intermediate selections
- capped at 99%

This is a **portfolio demonstration**, not a labor-market prediction model. Market values are illustrative and should not be treated as live salary data.

## Run locally

Open `index.html` in a modern browser. No installation is required.
