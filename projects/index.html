How the projects are judged

Not by how futuristic the landing page sounds—by whether the system explains itself and survives inspection.

Product test

  • Can a new user understand the purpose in seconds?
  • Is there a useful interaction beyond a screenshot?
  • Does the interface make the next action obvious?

Engineering test

  • Are assumptions and limitations explicit?
  • Can the user inspect outputs and reasoning?
  • Is the implementation honest about simulated vs real data?
