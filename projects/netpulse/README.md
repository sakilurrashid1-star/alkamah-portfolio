# NetPulse — Network Intelligence Lab

NetPulse is an interactive browser-based networking laboratory designed to make computer-network concepts visible and explorable instead of purely theoretical.

## Highlights

- 🗺️ Interactive network topology with client, router, firewall, API server, database and WAN nodes
- 📦 Animated packet-forwarding simulation and traffic bursts
- 📡 Network telemetry for latency, packet loss, throughput and packet counts
- 🧭 Routing-table visualization
- 🧮 CIDR subnet calculator with network, broadcast, host range, mask and capacity
- 🛰️ Simulated traceroute experience
- 🤝 Visual TCP three-way handshake
- 🧱 OSI 7-layer explorer with protocol examples
- 📊 Protocol activity visualization
- 📱 Responsive premium dark interface

## Why this project is different

The goal is not to build another static networking notes page. NetPulse turns networking fundamentals into an interactive command center so a learner or reviewer can observe how concepts such as routing, packet forwarding, TCP establishment, subnetting and protocol layers fit together.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- No backend
- No build tool
- No external runtime dependency

Telemetry values, packets, routes and traceroute results are simulated for learning and portfolio demonstration. NetPulse does not inspect or monitor real network traffic.
