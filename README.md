## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/sakilurrashid1-star/alkamah-portfolio.git
cd alkamah-portfolio
```

Open `index.html` directly in a browser, or serve the folder with a local development server.

## 🌍 GitHub Pages Deployment

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`.
5. Save the configuration.

The repository is structured specifically for this deployment workflow. fileciteturn5file0

## 🔄 Updating the Portfolio

Future website changes can be committed to the `main` branch. With GitHub Pages configured, GitHub will rebuild the published site from the latest repository contents.
